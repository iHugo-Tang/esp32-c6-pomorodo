# 显示、供电与输入

## 电池供电时的显示策略

两分钟没有触摸后，Running Timer 降到所选亮度的 60%，但保持可见。Ready、Paused 和 Completion Transition 降到 `Idle brightness`，默认 20%；这些非 Running 状态在五分钟后自动 Display Off。

Timer 完成会唤醒显示，即使已静音。静态内容每分钟最多偏移 2 px，阻塞对话框不移动。

## USB Power

USB Power 表示设备正在通过 USB 接收外部电源，与电池是否充电、串口是否连接无关。

USB Power 期间不自动调暗或 Display Off，所有页面使用正常或预览亮度。用户主动 Display Off 仍然有效，像素偏移继续工作。

接入 USB 会恢复因自动策略变暗或熄灭的显示，但不会唤醒用户主动关闭的显示。拔出 USB 后，从拔出时刻重新计算闲置时间。USB 状态变化不会模拟触摸，也不改变 Timer、Set Progress 或 Statistics。

## 触摸与唤醒

屏幕上的任何有效接触都会恢复所选亮度并重置闲置计时。若屏幕只是变暗，同一次接触继续执行原操作，而且只执行一次。

若屏幕已经关闭，第一次接触只唤醒，并消耗到手指抬起；不能同时触发点击、滑动或改值。下一次接触才正常操作。

## PWR 与硬件状态

短按 PWR 在 Display Off 与唤醒之间切换，一次按键就够。临时 UI 锁可以延迟处理，但不能丢失或重复处理。长按保持开发板关机行为。

Main 显示电量、充电状态和 USB Power。低电量只提示一次，不中止 Running Timer。RTC warning、Battery low 和 Volume feedback 共用一个不拦截输入的状态层，顺序固定。

## UI Orientation

QMI8658 根据重力选择 `0°`、`90°`、`180°` 或 `270°`，显示和触摸坐标一起旋转。设备平放、倾斜不明确或正在触摸时保持当前方向；触摸结束后再应用待定方向。

启动时先显示 `0°`。方向判断约每 100 ms 采样一次：主轴至少 `0.70g`、比另一轴至少高 `0.15g`，连续六次一致才旋转。

连续三次读取失败时保留当前方向，并在每次启动最多显示一次 `Auto-rotate unavailable`。设备每五秒重试，恢复后静默继续。旋转不能改变页面、滚动位置、对话框、Timer 状态或截止时间。
